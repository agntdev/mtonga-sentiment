# Project Plan

## Phase 1: Setup and UI
- Set up the project structure
- Create the UI with two big buttons for voting
- Add basic styling and layout

## Phase 2: Voting Logic
- Implement TonConnect integration for TON transactions
- Handle user votes with appropriate comments
- Validate transaction comments for 'yes' or 'no'

## Phase 3: On-Chain Data Reading
- Connect to TON API to read incoming transactions
- Scan for transactions to the designated address
- Parse comments to determine bullish or bearish votes

## Phase 4: Display Results
- Tally the votes and calculate percentages
- Display live results on the frontend
- Add a vote counter and percentage display

## Phase 5: Testing and Deployment
- Test the app locally and in a staging environment
- Fix any bugs or issues
- Deploy the app to a production environment
